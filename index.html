Welcome to #overview!

Client-sided two-way chat syncing between Minecraft and Discord.

Discord Addon APP Today at 12:00 AM
A lightweight Meteor Client addon that connects your in-game Minecraft chat to a Discord channel. Everything runs locally on your client—no server plugins or operator permissions needed.
How It Works
Uses a Discord Bot to read messages from your channel and send them in-game, and a Webhook to forward your in-game chat back to Discord.

Client-Side Only

#discord-to-mc

Module Category: Discord Addon — Incoming Discord Relay

Discord To Minecraft MODULE Today at 12:15 AM
Connects to a Discord Bot using JDA on a separate background thread so your game FPS never drops. Whenever a user types in the linked channel, your player automatically sends that message into Minecraft chat.
Settings & Behavior
Built-in loop protection automatically ignores bot accounts and webhook messages so relayed chat never echoes infinitely.

Discord Bot Token
channel-id
Target Channel ID
QrystalGG OWNER Today at 12:20 AM
How to set up Discord -> Minecraft:

1. Head to the Discord Developer Portal and create a New Application.
2. Go to the "Bot" tab, click "Reset Token", and copy your Bot Token. (Keep this secret!)
3. Scroll down on the Bot page and enable Message Content Intent.
4. Invite the bot to your server using the OAuth2 URL Generator (select `bot` scope and give it Read/Send Messages permissions).
5. Turn on Developer Mode in Discord (User Settings -> Advanced), right-click your desired channel, and click "Copy Channel ID".
6. Paste both into the Meteor Client GUI for this module and you're done!

#mc-to-discord

Module Category: Discord Addon — Outgoing Minecraft Relay

MinecraftToDiscord MODULE Today at 12:16 AM
Hooks into Meteor's ReceiveMessageEvent to capture incoming server chat and forward it directly to your Discord channel through a Webhook.
Settings & Behavior
Dispatches non-blocking HTTP POST requests via CompletableFuture so network latency never freezes your client tick loop.
webhook-url
Discord Webhook URL
Execution
Async HttpClient
QrystalGG OWNER Today at 12:22 AM
How to set up Minecraft -> Discord:

1. Open Discord and go to the channel you want to bridge.
2. Click the gear icon (Edit Channel) next to the channel name.
3. Go to Integrations -> Webhooks and click "New Webhook".
4. Customize the name/avatar if you want, then click "Copy Webhook URL".
5. Paste this URL into the Meteor Client GUI for this module. Any chat you see in-game will now be sent to Discord!
